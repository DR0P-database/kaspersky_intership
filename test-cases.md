# Тест-кейсы для проверки конфигурационного файла

## Общие проверки

| ID | Название теста | Описание | Входные данные | Ожидаемый результат |
|----|----------------|----------|----------------|---------------------|
| TC-001 | Отсутствует конфигурационный файл | Проверить поведение при отсутствии файла | config.ini отсутствует | Тест провален с сообщением об ошибке |
| TC-002 | Неверная структура INI | Отсутствуют секции или синтаксические ошибки | INI без секций | Тест провален с ошибкой синтаксиса |
| TC-003 | Пропущена секция General | В файле нет секции [General] | config.ini без [General] | Ошибка о недостающей секции |
| TC-004 | Пропущена секция Watchdog | В файле нет секции [Watchdog] | config.ini без [Watchdog] | Ошибка о недостающей секции |

## Проверка параметров секции [General]

| ID | Название теста | Описание | Входные данные | Ожидаемый результат |
|----|----------------|----------|----------------|---------------------|
| TC-101 | Некорректный ScanMemoryLimit | Значение вне диапазона [1024-8192] | 9000 | Ошибка валидации |
| TC-102 | Неверный тип ScanMemoryLimit | Не целое число | abc | Ошибка валидации |
| TC-103 | Допустимый PackageType | Проверка разных регистров | RPM, deb, DeB | Проходит |
| TC-104 | Недопустимый PackageType | Левое значение | tar.gz | Ошибка |
| TC-105 | AdditionalDNSLookup с неверным значением | Не boolean | maybe | Ошибка |
| TC-106 | CoreDumpsPath — несуществующий путь | Путь не существует | /fake/path | Ошибка |
| TC-107 | MachineId — неверный UUID | Неверный формат UUID | 1234 | Ошибка |
| TC-108 | Locale — неверный формат | Невалидная локаль | english_US | Ошибка |
| TC-109 | Все параметры корректны | Полный валидный конфиг | как в примере | Проходит успешно |

## Проверка параметров секции [Watchdog]

| ID | Название теста | Описание | Входные данные | Ожидаемый результат |
|----|----------------|----------|----------------|---------------------|
| TC-201 | ConnectTimeout без "m" | Целое без суффикса m | 10 | Ошибка |
| TC-202 | MaxMemory — off | Проверка допустимого значения | off | Проходит |
| TC-203 | MaxVirtualMemory — число вне диапазона | 150.5 | Ошибка |
| TC-204 | PingInterval — строка вместо числа | abc | Ошибка |
